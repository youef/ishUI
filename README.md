# ISH UI 5.6 — يوسف الحازمي

مركز أدوات طرفي خفيف لبيئة **iSH / Alpine Linux** على iPhone وiPad، مبني بمكتبات Python القياسية.

> يعمل داخل طرفية iSH بواجهة TUI نصية، وليس تطبيق iOS رسومي مستقلاً.

## أبرز ميزات 5.6
- لوحة ويب مطورة لإضافة النطاقات المصرح بها وحذفها مباشرة من المتصفح، مع عرض القائمة المحفوظة محلياً.
- أزرار تشغيل/إيقاف مؤقت للخدمة من لوحة الويب؛ تبقى صفحة التحكم متاحة لإعادة التشغيل دون الرجوع إلى القوائم النصية.
- عند اختيار خروج من واجهة الطرفية، تبقى عملية خادم الويب حية داخل iSH؛ استخدم Ctrl+C في جلسة iSH لإنهاء العملية بالكامل.
- حالة الخدمة ومدة تشغيل العملية ظاهرة في اللوحة، وتتعطل أوامر الأدوات والفحوصات عند إيقاف الخدمة مؤقتاً.

## أبرز ميزات 5.5
- خادم ويب محلي يبدأ تلقائياً مع تشغيل ISH UI، ولوحة تحكم عربية RTL على `http://127.0.0.1:8765` (قد يستخدم منفذاً قريباً إذا كان مشغولاً).
- الخادم مربوط بعنوان loopback فقط ولا يستقبل اتصالات الإنترنت المباشرة.
- أوامر ويب محددة وآمنة نسبياً (ملخص النظام والعمليات والشبكة والحزم والبحث في apk)، دون تنفيذ shell عشوائي.
- تثبيت حزم apk بعد موافقة صريحة، وتشغيل فحص نطاق موجود في قائمة التصريح، وعرض تقارير JSON المحفوظة.
- مهام الفحص التي تبدأ من الويب تعمل في عملية Python مستقلة وتكتب سجلها محلياً.

## أبرز ميزات 5.4
- شاشة ترحيب متحركة مع شريط تقدم لمدة 30 ثانية وانتقال تلقائي إلى لوحة التحكم.
- لوحة رئيسية تعرض الوقت وبيانات النظام والتخزين والثيم النشط.
- أربعة ثيمات: المحيط، ماتريكس، الغروب، وأحادي، مع حفظ الاختيار.
- مختبر تدقيق مواقع منخفض التأثير: DNS وTLS والشهادات وترويسات HTTP وCookies والتحويل إلى HTTPS وملفات robots/sitemap/security.txt.
- أدوات المطورين: JSON وBase64 وURL encode/decode وSHA-256/SHA-512 وقراءة JWT محلياً وطلب API GET محدود.
- مختبر أمن سيبراني متقدم: DNS وTLS وشهادات HTTPS وتحليل ترويسات HTTP وفحص TCP محدود حتى 8 منافذ وتحليل URL محلي وبصمات SHA-256 وتقييم كلمات المرور محلياً.
- أدوات الشبكة وإدارة النظام والملفات والحزم والعمليات والخدمات.
- نسخ احتياطي وأرشفة ZIP ومحرر نصوص وطرفية أوامر.
- تحديث Git يفحص التعديلات المحلية ويحاول حفظها واستعادتها قبل/بعد التحديث.

## التثبيت
```sh
apk update
apk add git python3
git clone https://github.com/youef/ishUI.git
cd ishUI
chmod +x install.sh
./install.sh
```

بعد التثبيت شغّل `ishui`.

## أوامر سريعة
```sh
ishui --help
ishui --version
ishui --doctor
ishui --backup
```

## محرك الفحص الذكي الدفعي 5.4
- أدخل النطاق الأساسي مرة واحدة؛ يجمع البرنامج DNS وIP الظاهر وTLS وHTTP ويفحص مؤشرات الأمان ومسارات عامة شائعة بطلبات HEAD محدودة.
- اكتشاف النطاقات المرشحة يتم من SAN في شهادة TLS وReverse DNS، ويمكن اختيار Reverse-IP lookup خارجي (HackerTarget). عند تفعيله يُرسل عنوان IP العام إلى المزود الخارجي، وقد يفرض المزود حدوداً على الطلبات.
- تُحفظ قائمة النطاقات المصرح بها في `~/.config/ishui/authorized_scope.json`. يضيف البرنامج النطاق الأساسي بعد تأكيدك، ولا يفحص المرشحين الآخرين إلا إذا كانوا موجودين في القائمة.
- تُفحص النطاقات المصرح بها التي ظهرت ضمن نتائج الاكتشاف دفعة واحدة وبالتتابع، مع التحقق من DNS العام لكل نطاق.
- يُحفظ كل تقرير بصيغة JSON داخل `~/.config/ishui/reports/`، والمهام ونقاط الاستئناف في `~/.config/ishui/security_jobs.sqlite3`.
- لا يعمل iSH في الخلفية بعد إغلاق التطبيق؛ عند العودة يمكن استئناف المهام المحفوظة.
- عنوان IP الظاهر قد يكون CDN أو reverse proxy وليس عنوان الخادم الأصلي (origin). لا يحاول البرنامج تجاوز CDN أو كشف origin المخفي.
- فحص المسارات يثبت استجابة المسار فقط ولا يختبر تسجيل الدخول أو يثبت وجود ثغرة. لا توجد payloads أو SQLi نشطة أو تخمين كلمات مرور أو استغلال.

## الأمن والاستخدام المسؤول
استخدم مختبر فحص المواقع فقط على المواقع التي تملكها أو لديك تصريح صريح بفحصها. الفاحص يرسل طلبات قياسية محدودة ولا ينفذ استغلالاً أو تخمين كلمات مرور أو فحص منافذ أو تجاوز صلاحيات. النتائج مؤشرات إعدادات وليست إثباتاً لوجود ثغرة.

أداة JWT تفك قراءة الرأس والحمولة فقط ولا تتحقق من التوقيع. أداة API تنفذ GET واحداً بمهلة قصيرة وحد أقصى لحجم الاستجابة.

## مختبر الأمن السيبراني
- جميع الأدوات مكتوبة بمكتبات Python القياسية، ولا تتطلب pip أو حزم Kali خارجية.
- فحص المنافذ محدود بـ 8 منافذ يحددها المستخدم وبمهلة اتصال قصيرة؛ استخدمه فقط على أصول تملكها أو لديك تصريح صريح لاختبارها.
- أداة تحليل URL لا تفتح الرابط. تقييم كلمة المرور محلي ولا يحفظها أو يرسلها.
- iSH لا يوفر كل قدرات Linux/Kali؛ لذلك لا تتضمن هذه النسخة التقاط الحزم أو وضع monitor أو أدوات تتطلب raw sockets أو صلاحيات root.

## ملاحظات iSH
- لا توجد خدمة سحابية أو إرسال تلقائي للبيانات.
- قد تختلف الوظائف حسب قيود iOS/iSH.
- لم يتم اختبار هذا التحديث على جهاز iPhone فعلي ضمن هذه العملية.

## لوحة تحكم الويب 5.5
- شغّل `ish`؛ يبدأ خادم الويب تلقائياً بعد شاشة الترحيب.
- افتح عنوان `http://127.0.0.1:8765` في متصفح الجهاز. إذا كان المنفذ مشغولاً، تعرض الواجهة المنفذ البديل في لوحة ISH UI.
- لا يتطلب رمز دخول؛ لذلك يجب إبقاء الخادم على `127.0.0.1` وعدم كشفه على الشبكة.
- تتضمن اللوحة حالة النظام، أوامر محددة، بحث/تثبيت حزم apk، تشغيل فحص نطاق مصرح به، وعرض التقارير.
- الخادم مربوط بـ `127.0.0.1` فقط عمداً؛ لا تغيّر ذلك إلى `0.0.0.0` ولا تعرضه عبر نفق عام دون طبقة مصادقة وشبكة آمنة إضافية.
- لا توجد واجهة لتنفيذ أوامر shell حرة من المتصفح؛ هذا يمنع تحويل لوحة الويب إلى باب تحكم عن بُعد مكشوف.
- بعد الخروج من واجهة الطرفية يبقى الخادم عاملاً ما دامت عملية iSH نشطة. زر إيقاف الخدمة في اللوحة يوقف وظائف الأدوات والفحص مع إبقاء صفحة التحكم لإعادة التشغيل.
- لا يستطيع iSH ضمان العمل 24/7 بعد إغلاق التطبيق أو تعليق iOS أو إنهاء النظام للعملية؛ للاستمرار الحقيقي بعد ذلك يلزم VPS أو جهاز دائم التشغيل.
