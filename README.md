# ISH UI 5.3 — يوسف الحازمي

مركز أدوات طرفي خفيف لبيئة **iSH / Alpine Linux** على iPhone وiPad، مبني بمكتبات Python القياسية.

> يعمل داخل طرفية iSH بواجهة TUI نصية، وليس تطبيق iOS رسومي مستقلاً.

## أبرز ميزات 5.3
- شاشة ترحيب متحركة مع شريط تقدم لمدة 30 ثانية وانتقال تلقائي إلى لوحة التحكم.
- لوحة رئيسية تعرض الوقت وبيانات النظام والتخزين والثيم النشط.
- أربعة ثيمات: المحيط، ماتريكس، الغروب، وأحادي، مع حفظ الاختيار.
- مختبر تدقيق مواقع منخفض التأثير: DNS وTLS والشهادات وترويسات HTTP وCookies والتحويل إلى HTTPS وملفات robots/sitemap/security.txt.
- أدوات المطورين: JSON وBase64 وURL encode/decode وSHA-256/SHA-512 وقراءة JWT محلياً وطلب API GET محدود.
- مختبر أمن سيبراني متقدم: DNS وTLS وشهادات HTTPS وتحليل ترويسات HTTP وفحص TCP محدود حتى 8 منافذ وتحليل URL محلي وبصمات SHA-256 وتقييم كلمات المرور محلياً.\n- أدوات الشبكة وإدارة النظام والملفات والحزم والعمليات والخدمات.
- نسخ احتياطي وأرشفة ZIP ومحرر نصوص وطرفية أوامر.
- تحديث Git يفحص التعديلات المحلية ويحاول حفظها واستعادتها قبل/بعد التحديث.

## التثبيت
```sh
apk update
apk add git python3
git clone https://github.com/youef/ishUI.git
cd ishUI
chmod +x install.sh
./install.sh
```

بعد التثبيت شغّل `ishui`.

## أوامر سريعة
```sh
ishui --help
ishui --version
ishui --doctor
ishui --backup
```

## محرك فحص المواقع واستئناف المهام\n- يبدأ الفحص بنطاق واحد محدد ويطلب تأكيد الملكية أو التصريح المكتوب.\n- يتحقق من أن عناوين DNS عامة، ويرفض العناوين الخاصة والمحلية، ويمنع التحويلات إلى مضيف آخر.\n- يفحص مجموعة صغيرة ثابتة من المسارات العامة بطريقة HEAD فقط؛ لا يجرب كلمات مرور ولا يرسل حقن SQL أو payloads ولا ينفذ استغلالاً.\n- تحفظ نقطة التقدم والنتائج في `~/.config/ishui/security_jobs.sqlite3`. عند إغلاق iSH تتوقف العملية بسبب قيود iOS، لكن يمكن استئناف المهمة المحفوظة بعد فتح التطبيق من جديد.\n- عنوان IP الذي يظهر عبر DNS قد يكون عنوان CDN أو reverse proxy، وليس بالضرورة عنوان الخادم الأصلي (origin). لا يحاول البرنامج تجاوز CDN أو كشف origin المخفي.\n\n## الأمن والاستخدام المسؤول
استخدم مختبر فحص المواقع فقط على المواقع التي تملكها أو لديك تصريح صريح بفحصها. الفاحص يرسل طلبات قياسية محدودة ولا ينفذ استغلالاً أو تخمين كلمات مرور أو فحص منافذ أو تجاوز صلاحيات. النتائج مؤشرات إعدادات وليست إثباتاً لوجود ثغرة.

أداة JWT تفك قراءة الرأس والحمولة فقط ولا تتحقق من التوقيع. أداة API تنفذ GET واحداً بمهلة قصيرة وحد أقصى لحجم الاستجابة.

## مختبر الأمن السيبراني\n- جميع الأدوات مكتوبة بمكتبات Python القياسية، ولا تتطلب pip أو حزم Kali خارجية.\n- فحص المنافذ محدود بـ 8 منافذ يحددها المستخدم وبمهلة اتصال قصيرة؛ استخدمه فقط على أصول تملكها أو لديك تصريح صريح لاختبارها.\n- أداة تحليل URL لا تفتح الرابط. تقييم كلمة المرور محلي ولا يحفظها أو يرسلها.\n- iSH لا يوفر كل قدرات Linux/Kali؛ لذلك لا تتضمن هذه النسخة التقاط الحزم أو وضع monitor أو أدوات تتطلب raw sockets أو صلاحيات root.\n\n## ملاحظات iSH
- لا توجد خدمة سحابية أو إرسال تلقائي للبيانات.
- قد تختلف الوظائف حسب قيود iOS/iSH.
- لم يتم اختبار هذا التحديث على جهاز iPhone فعلي ضمن هذه العملية.
