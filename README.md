# ISH UI — يوسف الحازمي

مركز تحكم تفاعلي مطوّر يعمل داخل تطبيق **iSH** على iPhone وiPad، مبني باستخدام Python ومكتباته القياسية فقط.

> **تنبيه مهم:** iSH عبارة عن بيئة Linux طرفية على iOS. لذلك ISH UI واجهة إدارة نصية متقدمة داخل الطرفية، وليست تطبيق سطح مكتب رسومي مستقل.

## التثبيت لأول مرة

افتح iSH ونفّذ:

```sh
apk update
apk add git python3
git clone https://github.com/youef/ishUI.git
cd ishUI
chmod +x install.sh
./install.sh
```

بعدها شغّل:

```sh
ishui
```

ويمكن التشغيل مباشرة دون أمر التثبيت:

```sh
python3 ishui.py
```

## المزايا في الإصدار 2.0

- **لوحة رئيسية:** معلومات بيئة التشغيل واستخدام مساحة التخزين.
- **مدير حزم Alpine:** تحديث المستودعات، ترقية الحزم، تثبيت/حذف/بحث وعرض الحزم.
- **مستكشف ملفات:** التنقل بين المجلدات، معاينة الملفات النصية، إنشاء ملفات ومجلدات، نسخ ونقل وحذف الملفات مع تأكيد الحذف.
- **طرفية أوامر:** تنفيذ أوامر shell مع حفظ سجل الأوامر محلياً.
- **مراقبة النظام:** عرض العمليات، معلومات التخزين والذاكرة عند توفرها.
- **أدوات الشبكة:** معلومات الشبكة، اختبار Ping، واستعلام DNS.
- **معلومات النظام:** إصدار النظام والنواة والمعمارية وPython وبيانات الجهاز.
- **تحديث ذاتي:** جلب آخر إصدار من GitHub عند تثبيت المشروع باستخدام git clone.
- **إعدادات:** تشغيل/إيقاف الألوان والساعة، مع حفظ التفضيلات محلياً.

## التحديث

من داخل مجلد المشروع:

```sh
git pull --ff-only
```

أو افتح ISH UI واختر «تحديث ISH UI».

## الملفات

- `ishui.py` — التطبيق الرئيسي.
- `install.sh` — سكربت التثبيت.
- `README.md` — هذا الدليل.

## الخصوصية والسلامة

- لا توجد خدمة سحابية أو إرسال تلقائي للبيانات.
- الإعدادات وسجل الأوامر محفوظان محلياً داخل مجلد المستخدم.
- منفذ الأوامر يشغّل ما تكتبه أنت بصلاحيات المستخدم الحالي؛ لا تشغّل أوامر لا تفهمها.
- حذف الملفات نهائي من بيئة iSH، ويطلب البرنامج تأكيداً قبل الحذف.
- بعض معلومات النظام والشبكة قد لا تكون متاحة بسبب حدود بيئة iSH.
