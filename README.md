# ISH UI 3.1 — يوسف الحازمي

مركز إدارة متقدم لبيئة **iSH / Alpine Linux** على iPhone وiPad. الإصدار 3.1 يضيف واجهة طرفية بأيقونات، وفاحص مواقع سلبي لـ HTTP/HTTPS وDNS وTLS وترويسات الأمان، مع أدوات تثبيت وفحص الحزم.

> **طبيعة التطبيق:** iSH بيئة Linux طرفية على iOS؛ لذلك ISH UI واجهة TUI نصية داخل الطرفية، وليس تطبيق iOS رسومي مستقلاً.

## التثبيت

```sh
apk update
apk add git python3
git clone https://github.com/youef/ishUI.git
cd ishUI
chmod +x install.sh
./install.sh
```

شغّل التطبيق: `ishui` أو `python3 ishui.py`.

## الجديد في 3.0

- لوحة معلومات النظام والتخزين والمعمارية.
- مدير حزم Alpine: تحديث وترقية وتثبيت وحذف وبحث.
- مستكشف ملفات: تنقل ومعاينة وإنشاء ونسخ ونقل وحذف.
- محرر نصوص مع نسخة `.bak` قبل استبدال الملف.
- مدير عمليات لعرض العمليات وإرسال SIGTERM إلى PID تختاره.
- مدير خدمات OpenRC عند توفر `rc-service`.
- نسخ احتياطي واستعادة ملفات المستخدم في أرشيف `tar.gz` مع فحص مسارات الاستخراج.
- مدير ZIP لإنشاء الأرشيفات وعرضها واستخراجها مع منع اجتياز المسارات.
- أدوات الشبكة: Ping وDNS ومعلومات الواجهات.
- فحص تشخيصي للأدوات الأساسية والاتصال بـ GitHub.
- فاحص مواقع: DNS، حالة HTTP، زمن الاستجابة، شهادة TLS، وترويسات الأمان الشائعة.
- مدير أدوات الفحص يتحقق من `curl` و`wget` و`nslookup` و`openssl` وشهادات CA، ويثبت الناقص منها عبر `apk` بعد موافقتك.
- واجهة قوائم بأيقونات وألوان، مع الاعتماد على مكتبات Python القياسية لتبقى خفيفة.
- تحديث ذاتي عبر Git وإعدادات محلية وسجل أوامر.


## التحديث

من داخل مجلد المشروع: `git pull --ff-only`، أو اختر «تحديث ISH UI» من القائمة.

## فحص المواقع

من القائمة الرئيسية اختر `15` ثم أدخل رابط موقع تملكه أو لديك تصريح بفحصه. الفحص غير تدميري ولا ينفذ استغلالاً للثغرات؛ يعرض DNS وTLS وHTTP وبعض ترويسات الأمان فقط. غياب ترويسة لا يثبت وحده وجود ثغرة، والنتائج ليست بديلاً عن تدقيق أمني متخصص.

## الخصوصية والسلامة

- لا توجد خدمة سحابية أو إرسال تلقائي للبيانات.
- الإعدادات وسجل الأوامر والنسخ الاحتياطية تبقى محلياً داخل مجلد المستخدم.
- منفذ الأوامر ينفذ ما تكتبه بصلاحيات iSH الحالية؛ تعامل مع الأوامر بحذر.
- حذف الملفات نهائي؛ راجع المسار قبل التأكيد.
- الاستعادة قد تستبدل ملفات موجودة؛ راجع النسخة قبل الموافقة.
- قد لا تتوفر بعض أدوات النظام بسبب قيود iOS/iSH.
- لم يتم اختبار التشغيل على جهاز iPhone فعلي ضمن هذه العملية.
