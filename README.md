# ISH UI 4.0 — يوسف الحازمي

مركز أدوات نصّي متكامل لبيئة **iSH / Alpine Linux** على iPhone وiPad. إصدار 4.0 يضيف شاشة ترحيب قبل لوحة الأدوات، ويعيد تنظيم قسم الويب ليقدّم مراجعة إعدادات أمنية منخفضة التأثير.

> **طبيعة المشروع:** يعمل داخل طرفية iSH كواجهة TUI نصية، وليس تطبيق iOS رسومي مستقلاً.

## التثبيت والتشغيل

```sh
apk update
apk add git python3
git clone https://github.com/youef/ishUI.git
cd ishUI
chmod +x install.sh
./install.sh
```

بعد التثبيت شغّل `ishui` أو `python3 ishui.py`.

## تجربة الإصدار 4.0

- شاشة ترحيبية باسم ISH UI وتوقيع المطوّر، ثم الانتقال إلى لوحة الأدوات.
- لوحة طرفية خفيفة ومناسبة لشاشات iPhone الصغيرة.
- إدارة حزم Alpine ومستكشف ملفات ومحرر نصوص وطرفية أوامر.
- مراقبة النظام ومعلومات البيئة ومدير العمليات وخدمات OpenRC.
- النسخ الاحتياطي والاستعادة وإدارة أرشيف ZIP.
- أدوات الشبكة: معلومات الواجهات وPing وDNS.
- تدقيق إعدادات الويب: حل DNS، والتحقق من TLS وشهادة الموقع ومدة صلاحيتها، وحالة HTTP، وترويسات الأمان، وبعض سمات الكوكيز، والتحقق من التحويل إلى HTTPS.
- فحص ملفات التعريف العامة المعروفة فقط: `robots.txt` و`sitemap.xml` و`/.well-known/security.txt`.
- إدارة أدوات مساعدة مثل curl وwget وnslookup وOpenSSL وشهادات CA.
- إعدادات محلية وسجل أوامر وتحديث عبر Git.

## تدقيق الويب وحدود الفحص

استخدم أدوات التدقيق فقط على المواقع التي تملكها أو لديك تصريح صريح بفحصها. الفاحص يرسل طلبات HTTP قياسية محدودة ولا ينفذ استغلالاً للثغرات، ولا يخمّن كلمات المرور، ولا يجري فحص منافذ أو تخمين مسارات أو تجاوز صلاحيات.

النتائج مؤشرات لإعدادات قد تحتاج مراجعة، وليست إثباتاً لوجود ثغرة أو بديلاً عن اختبار اختراق احترافي. غياب ترويسة معينة لا يعني وحده أن الموقع مخترق أو ضعيف؛ يجب تقييمها وفق طبيعة التطبيق.

## أوامر سريعة

```sh
ishui --help
ishui --version
ishui --doctor
ishui --backup
```

## التحديث

من داخل مجلد المشروع:

```sh
git pull --ff-only
```

أو اختر «تحديث ISH UI» من لوحة الأدوات.

## الخصوصية والقيود

- لا توجد خدمة سحابية أو إرسال تلقائي للبيانات.
- الإعدادات وسجل الأوامر والنسخ الاحتياطية محفوظة محلياً.
- منفذ الأوامر ينفذ أوامرك بصلاحيات iSH الحالية؛ تعامل معها بحذر.
- قد لا تتوفر بعض وظائف Linux بسبب قيود iOS/iSH.
- لم يتم اختبار التشغيل على جهاز iPhone فعلي ضمن هذا التحديث.
